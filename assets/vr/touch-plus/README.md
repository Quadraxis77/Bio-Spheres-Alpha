# Quest 3 Touch Plus controller assets

The unmodified left/right GLB files and profile.json are from the Immersive Web
Working Group's WebXR Input Profiles asset collection:
https://github.com/immersive-web/webxr-input-profiles/tree/main/packages/assets/profiles/meta-quest-touch-plus

Downloaded October 6, 2026. The accompanying LICENSE.md is the asset package's
MIT license, including its copyright notice:
https://github.com/immersive-web/webxr-input-profiles/blob/main/packages/assets/LICENSE.md

The executable embeds the original meshes and textures. All glTF scene node
transforms are applied to render the models in meters relative to each OpenXR
grip pose. The original controller button labels and material textures are
preserved. Buttons are currently rendered in their resting position.
